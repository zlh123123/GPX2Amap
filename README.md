# GPX2Amap

一个中文 Chrome Manifest V3 扩展：把 GPX 轨迹转换成高德新版路线链接，并用最多 16 个有序途经点约束高德重新规划路线。

## 功能

- 点击选择或拖放上传 GPX 文件；
- 在浏览器本地解析轨迹，不上传 GPX；
- 默认把 WGS84 坐标转换为 GCJ-02；
- 可选择跳过转换，适配已经使用高德坐标系的 GPX；
- 使用 RDP 形状简化并补充高转向点；
- 生成高德路线链接；
- 一键复制链接或跳转高德页面。

高德会根据这些点重新规划道路，因此生成结果适合路线重建，不保证逐点复现原始 GPX。复杂路口、桥梁和轮渡区域建议打开链接后检查，并使用高德的途经点拖动功能微调。

## 本地安装

1. 打开 Chrome 的 `chrome://extensions`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择本项目目录；
5. 打开高德页面，点击扩展图标打开侧边栏；
6. 上传 GPX 或拖入 GPX 文件。

## 开发检查

```bash
npm test
npm run check
```

## 坐标和隐私

GPX 文件只在侧边栏页面中解析。插件不配置高德 REST Key，也不把轨迹发送到自建服务器。默认转换适用于通常的 WGS84 GPX；如果轨迹来源已经使用 GCJ-02，请勾选跳过转换。

## 发布

Chrome 网上应用店和 Microsoft Edge 加载项都支持 Manifest V3。发布前需要分别注册开发者账号、上传包含 `manifest.json` 的 ZIP 包，并填写隐私说明、图标和截图。详细步骤见 [浏览器商店发布说明](docs/发布到浏览器商店.md)。
