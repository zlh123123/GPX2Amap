# GPX2Amap 隐私政策

最后更新：2026 年 10 月 28 日

GPX2Amap 是一个在浏览器本地运行的开源浏览器扩展。

## 数据处理

- 用户选择的 GPX 文件只在扩展侧边栏中读取和解析；
- GPX 文件、轨迹坐标和生成的链接不会上传到 GPX2Amap 的服务器；
- 扩展不收集账号、姓名、邮箱、密码或浏览历史；
- 用户点击“跳转高德”后，生成的路线参数会随浏览器请求发送给高德网站，这是完成路线展示所必需的。

## 权限用途

扩展使用侧边栏显示操作界面，并使用标签页能力打开生成的高德路线链接。高德页面权限仅用于兼容高德路线页面和现有的页面检测能力。

## 联系方式

如发现隐私或安全问题，请在 GitHub 仓库提交 Issue。
