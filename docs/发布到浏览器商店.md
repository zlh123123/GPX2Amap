# 发布到浏览器商店

## Chrome 网上应用店

1. 注册 Chrome Web Store Developer 账号并支付一次性开发者注册费。
2. 在开发者控制台创建新项目。
3. 使用项目根目录打包 ZIP，压缩包顶层必须直接包含 `manifest.json`。
4. 上传 ZIP，填写中文名称、中文简介、图标、截图、隐私说明和支持邮箱。
5. 在隐私设置中说明：GPX 只在浏览器本地解析，不上传到服务器；插件会打开高德路线链接。
6. 选择公开发布，提交审核。

## Microsoft Edge 加载项

1. 注册 Microsoft Partner Center 开发者账号并完成身份验证。
2. 创建新的 Edge 扩展，上传同一个 ZIP 包。
3. 填写名称、描述、分类、图标、截图、隐私政策和支持信息。
4. 提交认证审核。

Chrome 和 Edge 都支持直接上传 Manifest V3 扩展。首次发布前建议先使用开发者模式加载解压目录完成手工测试，再上传商店包。商店审核要求、费用和表单字段可能会变化，应以各自控制台当前页面为准。
